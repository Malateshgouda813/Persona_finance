# Persona_finance

A simple and responsive **Budget Management Web App** built using **HTML, CSS, and JavaScript**.  
This application helps users manage their budget, track expenses, and calculate the remaining balance in real time.

---

# Features

- ✅ Set total budget
- ✅ Add expense title and amount
- ✅ Automatic balance calculation
- ✅ Real-time expense tracking
- ✅ Edit expenses
- ✅ Delete expenses
- ✅ Responsive user interface
- ✅ Simple and clean design

# 📖 How to Use

### Step 1:
Enter your total budget.

### Step 2:
Click on the **Set Budget** button.

### Step 3:
Enter:
- Expense title
- Expense amount

### Step 4:
Click on **Check Amount**.

### Step 5:
The application will automatically update:
- Total Budget
- Total Expenses
- Remaining Balance
- Expense List

### Additional Features:
- ✏️ Edit expenses
- 🗑️ Delete expenses
